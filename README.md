## 🚀 Run locally

Download or clone the repository:

```bash
git clone https://github.com/sabamadadi/sabamadadi.github.io.git
cd sabamadadi.github.io
```

Open `index.html` in your browser. You can navigate to the other pages using the links on the site. No dependencies are needed.

## 🌍 Deploy with GitHub Pages

1. Upload the **contents** of this repository to the `main` branch of `sabamadadi/sabamadadi.github.io`.
2. Keep `index.html` and the `assets/` directory at the **repository root**.
3. In **Settings → Pages**, configure publishing from the `main` branch and `/ (root)` if not already enabled.
4. Visit [sabamadadi.github.io](https://sabamadadi.github.io/) after deployment finishes.

> 💡 **Photo not showing?** Make sure `assets/profile.jpg` exists and opens at `https://sabamadadi.github.io/assets/profile.jpg`. File paths are case-sensitive. Try a hard refresh (`Ctrl + Shift + R`) after updating.
